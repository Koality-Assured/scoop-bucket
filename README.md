# scoop-bucket

Official Scoop bucket for [Koality-Assured](https://github.com/Koality-Assured) developer tooling and domain harnesses.

## Installation

Add this bucket to Scoop:

```powershell
scoop bucket add koality https://github.com/Koality-Assured/scoop-bucket
```

Install `harness`:

```powershell
scoop install harness
```

Update `harness`:

```powershell
scoop update harness
```
